# Instrucciones para Claude

- Todo cambio se entrega con un pull request a `main`, siempre. No se pushea directo a `main`.
- Textos del sitio en español rioplatense con voseo. Los contenidos viven en `content/` y los tokens de diseño en `app/globals.css`.
- Antes de abrir el PR, `npm run build` tiene que terminar sin errores.
